# Akhilesh A — Developer Portfolio

Personal developer portfolio website showcasing my projects, technical skills, education, and experience.

⚡️ **Live Local Preview:** `http://localhost:3000/`

---

## 🚀 Key Features

* **Bento Grid UI:** Modern, clean cards styled with translucent frosted-glass aesthetic.
* **Interactive Particle System:** HTML5 canvas background particles that react to cursor velocity and proximity with dynamic repulsion and constellation lines.
* **Ambient Color Shifting:** Real-time smooth hue transitions that track cursor movement across the viewport.
* **FormSubmit Integration:** Contact form forwarding messages directly to `akhileshaitham28@gmail.com` with automated confirmation receipts sent to the sender.
* **Fully Responsive:** 100% fluid layout optimized for both mobile phones and desktop displays.
* **Cyber Emerald Theme:** Custom emerald & neon cyan aesthetic with dynamic cursor lighting.
* **Dark / Light Mode:** Built-in theme toggler with persistent state.

---

## 🛠️ Tech Stack

* **Frontend:** React 18, React Router v6, Styled Components, Bootstrap 5
* **Build Tool:** Vite
* **Animations:** Canvas Particle Physics, React Awesome Reveal, Typewriter Effect
* **Contact Service:** FormSubmit

---

## 💻 Local Setup & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tamilselvanv00289/portfolio-akhilesh.git
   cd portfolio-akhilesh
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
